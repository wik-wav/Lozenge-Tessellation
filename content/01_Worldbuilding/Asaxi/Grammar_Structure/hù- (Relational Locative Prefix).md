# hù- ([[07_Describing Location in Asaxi]])

- - -

<span class="asaxi-script">hù-</span>

### Grammatical function

- **Type:** Relational Locative Prefix
- **Function:** Topological State (Posterior)
- **Meaning:** Behind, at the back of.

### Syntax

Attaches to the front of the noun.

- **Compound:** `hù` + `o` → **hùwo** (Behind-here).

### Pronunciation

IPA: /hɯ/

### Example sentence

**To John hùkamm xiŕa.** _John is behind the building._

### Derived terms

- **hùnů** - To be behind.
- **hùŕa** - To be behind (Stative).
- **hùzè-** (Pluperfect Tense: "Behind the past").
