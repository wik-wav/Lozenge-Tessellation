# gă ([[07_Describing Location in Asaxi|Indefinite Locative Prefix]])

- - -

<span class="asaxi-script">gă</span>

<span class="asaxi-script-alpha">gă</span>
### Grammatical function

#### As Indefinite Locative Prefix

- This word marks a noun as being "somewhere".
- Used when the object itself is not specific.
- Used when the object is known/specific, but its location is currently unknown to the speaker.
#### As a noun

As a noun, [[gă (noun)]] refers to somewhere (an unknown place).

#### As an adverb

As an adverb, `gă` refers to the thing or place in an unknown location. (e.g, `O-gă.` "(it) (is) somewhere here").

### Pronunciation

IPA: /ɡaɪ/

### Translation

- English: somewhere
- Polish: gdzieś

### Etymology

from japanese 外 (がい) outside, beyond, not included in
