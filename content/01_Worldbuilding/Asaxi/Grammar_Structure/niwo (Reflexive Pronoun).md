# niwo ([[13_Pronouns in Asaxi]])

- - -

<span class="asaxi-script">niwo</span>

### Grammatical function

- **Type:** Reflexive Pronoun
- **Function:** **Self-Reference**
- **Meaning:** "Myself". Indicates that the object of the verb is the same as the First Person Subject.

### Usage Note (Derivation)

Reflexive pronouns are formed by attaching the Allative prefix **ni-** (Towards) to the standard pronoun.

- **Formula:** `ni` + `[Pronoun]`.
- _Logic:_ "Towards \[Person\]." The action returns to its source.

### Pronunciation

IPA: /ɲiwo/

### Example sentence

**To wo niwo ijo.** _I see myself._

**[[ni (Relational Particle)|ni]]** (Towards) + **[[wo (Pronoun)|wo]]** (I).
