# nỏcè ([[01_Asaxi Nouns (List)]])

- - -

<span class="asaxi-script">nỏcè</span>

### Noun class (warm / cold)

**Cold**
- Reasoning: Inanimate record/information.

### Pronunciation

IPA: /nou̯t͡sə/

### Semantic field

[[Smntc_Field Perception]] / Communication / Education

### Translations

- English: note, memo, entry, record, reminder
- Polish: notatka, wpis, zapisek

### Usage Note

Refers to personal writing or short records, distinct from **[[shěso (noun)|shěso]]** (Book/Formal Text).

### Example sentence

**To wo nỏcè ijo.**
_I see the note._

### Etymology

A blend of English **"Note"** and the Asaxi components **[[nỏ (Particle)|nỏ]]** (Not) + **[[cè (verb)|cè]]** (Know).
*Lit:* "Not-Know." (Writing something down because you might not know/remember it later).

### Derived terms

- **nỏcèŕů** (To write a note / To journal).
