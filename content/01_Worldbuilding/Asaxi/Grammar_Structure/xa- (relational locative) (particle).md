# xa- ([[07_Describing Location in Asaxi]])

- - -

<span class="asaxi-script">xa-</span>

<span class="asaxi-script-alpha">xa-</span>
### Grammatical function

- **Type:** Relational Locative Prefix
- **Function:** Topological State (Superior/Non-contact)
- **Meaning:** Above, over, hovering over.

### Syntax

Attaches to the front of the noun.

- **Compound:** `xa` + `o` → **xawo** (Above-here).

### Pronunciation

IPA: /ɦa/

### Pitch Accent

- **Morae:** <span class="asaxi-text">xa</span>
- **Pattern:** `L`
- **Class:** `atonal`

### Example sentence


#### Example 1

- **Asaxi:** mao xasiŕo vaŕa.
- **English:** The moon is (contained) in outer space.
- **Polish:** x

### Derived terms

- **xanů** - To be above.
- **xaŕa** - To be above (Stative).
