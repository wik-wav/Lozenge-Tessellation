# gănå ([[18_Conjunctions & Clause Linking]])

- - -

<span class="asaxi-script">gănå</span>

### Grammatical function

- **Type:** Frequency Particle / Adverb
- **Function:** **Indefinite Future Frequency**
- **Meaning:** "Sometime", "One day", "Eventually" (with potential for never happening).

### Pronunciation

IPA: /ɡaɪnau̯/

### Logic & Etymology

**[[gă (Proximal Locative Prefix)|gă]]** (Somewhere/Indefinite) + **[[nå (NOW Aspectual Marker)|nå]]** (Now).

- _Lit:_ "Somewhere-time."
- _Logic:_ A point in time that exists "somewhere" but is not fixed. Unlike `ågă` (which is a Noun), `gănå` functions as an adverbial particle.

### Syntax

Used primarily with the **Future Tense** (`pa-`) or **Suppositional Statives**.

### Example sentence

**To wo pashěsonů gănå.** _I will read sometime (maybe)._
