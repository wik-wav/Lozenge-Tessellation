# The Asaxi Spatial Tense System

Asaxi constructs time by placing the action on a physical timeline relative to **nå** (Now).

| Tense / Aspect          | Prefix / Particle | Logic        | Literal Construction     | Example Meaning                  |
| ----------------------- | ----------------- | ------------ | ------------------------ | -------------------------------- |
| **Non-Past**            | **(Unmarked)**    | Default      | `[Verb]`                 | I read / I am reading.           |
| **Future**              | **pa-**           | Front        | `front-[Verb]`           | I **will** read.                 |
| **Simple Past**         | **zè-**           | Past         | `past-[Verb]`            | I read / I was reading.          |
| **Immediate Future**    | **opa-**          | Here-Front   | `here-front-[Verb]`      | I am **about to** read.          |
| **Immediate Past**      | **ozè-**          | Here-Past    | `here-past-[Verb]`       | I **just** read.                 |
| **Future Perfect**      | **pazè-**         | Front-Past   | `front-past-[Verb]`      | I **will have** read.            |
| **Pluperfect**          | **hùzè-**         | Behind-Past  | `behind-past-[Verb]`     | I **had** read.                  |
| **Past Future**         | **hùpa-**         | Behind-Front | `behind-front-[Verb]`    | I **was going to** read.         |
| **Habitual Past**       | **izozè-**        | From-Past    | `source-past-[Verb]`     | I **used to** read.              |
| **Perfect Progressive** | **nixå** (Arg)    | Into-Time    | `[nixå Duration] [Verb]` | I **have been** reading (for X). |
| **Prospective**         | **panå** (Part)   | Front-Now    | `[Verb] panå`            | I have **not yet** read.         |
### The Prefix Order (Stacking Rule)

When multiple prefixes are used, they stack **from the outside in**.

**Formula:**

> `[Tense]` + `[Negation]` + `[Aspect]` + `[Voice]` + `[Bridge]` + `[Root]`

**The Aspect Slot:** This slot is mutually exclusive. You generally choose **one** aspectual texture.

- **ni-** (Start)
- **chå-** (Finish)
- **na-** (Redo)

**Example:** "I did not start to read."

> **zè** (Past) + **ná** (Not) + **ni** (Start) + **shěsonů** (Read) → **zènánishěsonů**

**Example:** "I will start to read."

> **pa** (Future) + **ni** (Start) + **shěsonů** (Read) → **panishěsonů**
