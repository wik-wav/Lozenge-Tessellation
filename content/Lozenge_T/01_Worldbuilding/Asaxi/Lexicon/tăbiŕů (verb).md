# tăbiŕů ([[02_Asaxi Verbs_ů (List)]])

- - -

<span class="asaxi-script">tăbiŕů</span>

### Transitivity / Valency

**Transitive**
Takes an object (the image, diagram, or thing being drawn).

### Lexical Aspect

**Accomplishment:** The creation of an image.

### Grammatical Note

Derived from the compound root **tăbi** (Line-Assembly) + **[[06A_-ŕ- (Morphological Infix)|-ŕ-]]** (Generative Mode) + **-ů**.

### Semantic Field

[[Smntc_Field Arts]] / [[Smntc_Field Behaviour]]

### Pronunciation

IPA: /t̪aɪbiɾuw/

### Translations

- English: to draw, to sketch, to draft, to diagram
- Polish: rysować, szkicować

### Usage Note

Refers specifically to **dry media** or **line-based** creation (pencil, pen, chalk). For painting (liquid/colour), use **[[iŕoŕů (verb)|iŕoŕů]]** (To colour/shine) or **[[gámŕonů (verb)|gámŕonů]]** (To paint).

### Example sentence

**To wo o-shá tăbiŕů.**
_I draw this person._

### Etymology

**[[tă (Mathematical Operator)|tă]]** (Add/Assemble) + **[[bi (noun)|bi]]** (Line) + **-ŕ-** (Generate) + **-ů**.
*Lit:* "To generate added-lines."
