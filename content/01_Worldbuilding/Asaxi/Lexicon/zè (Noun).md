# zè ([[01_Asaxi Nouns (List)]])

- - -

<span class="asaxi-script">zè</span>

### Noun class (warm / cold)

**Cold**
- Reasoning: Abstract concept of time.

### Grammatical function

- **Type:** Temporal Noun
- **Meaning:** The Past, antiquity, previous times.

### Pronunciation

IPA: /zə/

### Semantic field

[[Smntc_Field Time]]

### Translations

- English: the past, history, yesterday (poetic)
- Polish: przeszłość

### Usage Note

Used with locative prefixes to describe *where* an event is in time.
* **vazè:** "In the past."
* **nizè:** "Into the past."

### Example sentence

**To xő vazè vanů.**
_He lives in the past._

### Etymology

Nominalization of the **[[zè (Tense Prefix)|zè-]]** (Past Tense Prefix).

### Antonyms

- **[[pa (Noun)|pa]]** (The Future).

### Derived terms

- **kozè** (Distant Past).
- **ozè** (Immediate Past).
