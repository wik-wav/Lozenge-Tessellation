# hjigo ([[01_Asaxi Nouns (List)]])

- - -

<span class="asaxi-script">hjigo</span>

<span class="asaxi-script-alpha">hjigo</span>
### Noun class (warm / cold)

**Cold**
- Reasoning: Abstract quantity.

### Grammatical function

- **Type:** Number Noun (Indefinite Quantifier)
- **Meaning:** "Few", "Little", "Not many", "A small number of".

### Usage Notes

Functions as a **Floating Quantifier**.
* **Structure:** `hjigo [Noun]` or `[Noun] hjigo`.

### Pronunciation

IPA: /çiɡo/
*Phonotactics:* `hj` becomes the voiceless palatal fricative /ç/.

### Semantic field

[[Smntc_Field Numerals]]

### Translations

- English: few, little (quantity), scarce
- Polish: mało, niewiele

### Example sentence

**Hjigo sháma zèxăja.**
_Few people shouted._

### Etymology

**[[hji (noun)|hji]]** (Smallness/Slightness) + **[[sigo (noun)|(si)go]]** (Number).
*Lit:* "Small-Number."

### Antonyms

- **[[dăgo (Quantifier)|dăgo]]** (Many / Big-Number).

### Derived terms

- **-go** quantifier family: [[dăgo (Quantifier)|dăgo]] (many), [[fůtăgo (Quantifier)|fůtăgo]] (some)
