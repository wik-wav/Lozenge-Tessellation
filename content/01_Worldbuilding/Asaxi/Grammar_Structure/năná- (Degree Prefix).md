# năná- ([[29_Degree & Comparison]])

- - -

<span class="asaxi-script">năná-</span>

<span class="asaxi-script-alpha">năná-</span>
### Grammatical function

- **Type:** Superlative Prefix
- **Function:** **Minimum Degree** ("Least")
- **Constraint:** Used only when the Adjective's source noun is **Warm**.

### Pronunciation

IPA: /naɪnɑ/

### Etymology

**nă-** (Warm Superlative) + **[[ná (Particle)|ná]]** (Not).

### Example sentence

**To John nănájýnă ůsů.** _John sounds the **least loudly** (hyena-like)._

- _Adverb:_ `jýnă` (Hyena-like/Loud - Warm Source `jýnnshá`)
- _Verbal Mode:_ `-w-` (Semblance/Acting).
