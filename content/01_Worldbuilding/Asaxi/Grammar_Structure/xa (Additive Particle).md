# xa ([[02_Particles in Asaxi]])

- - -

<span class="asaxi-script">xa</span>

<span class="asaxi-script-alpha">xa</span>
### Grammatical function

- **Particle type:** [[02_Particles in Asaxi|Low Binding Particle]] (Additive Focus)
- **Function:** **Additive / Scalar Focus Marker**
- **Meaning:** "Also", "Too", "As well"; with scalar force: "Even".

### Usage Notes

- **Position:** **Post-positioned** to the constituent it marks (unlike NPCP case particles, which precede): `[Noun/Pronoun] + xa`.
- **Additive:** **Ko xa xogă.** ("She also arrived.")
- **Standalone reply:** **Wo xa.** ("Me too.")
- **Scalar ("even"):** **Hjá xa cő.** ("Even a child understands.")

### Disambiguation (Homophones)

Distinct from **[[xa (Pronoun)|xa]]** (3PL.M pronoun), **[[xa- (Number Prefix)|xa-]]**, and **[[xa- (Relational Locative Prefix)|xa-]]** (above). The additive particle never takes the subject slot and never prefixes — position resolves all cases.

### Pronunciation

IPA: /ɦa/

### Example sentence

**To wo xa ni daoŕo aśù.**
_"I, too, am walking to the market."_

### Etymology

Extracted from canonical **[[chěxa (EVEN IF Conditional Compound)|chěxa]]** ("even if" = `chě` IF + `xa` EVEN), which preserves the particle in its scalar sense.
