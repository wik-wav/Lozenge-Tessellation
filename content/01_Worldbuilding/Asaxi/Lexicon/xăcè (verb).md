### Transitivity / Valency
**Monotransitive** (Knowing X for a fact).

### Lexical Aspect
- **State** — an ongoing condition, not an event.
- **Aspect markers**: **na-** "do repeatedly" · **tå-** "do once" · **ni-** "begin to" · **chå-** "do fully".

### Grammatical Note
**[[02_Asaxi Verbs_Root (List)]]:** Compound root verb.

### Semantic Field
[[Smntc_Field Perception]] / Cognition

### Pronunciation
IPA: /ɦaɪt͡sə/

### Translations
- English: to be sure, to know for a fact, to be certain, to verify
- Polish: być pewnym, wiedzieć na pewno

### Example sentence
**To wo tte xăcè.**
_I am sure of it._

### Alternative Forms
Null

### Etymology
**[[xă (Particle)|xă-]]** (Truly/Indeed) + **[[cè (verb)|cè]]** (Know).
*Lit:* "Truly-know."

### Synonyms
Null

### Antonyms
- **[[pùŕima (verb)]]** (To suspect/doubt).

### Derived terms
- [[xăcèno (noun)|xăcèno]] - truth, fact
### Usage Note
Used with **tte** for the expression **tte xăcè** ("I am sure that...").
