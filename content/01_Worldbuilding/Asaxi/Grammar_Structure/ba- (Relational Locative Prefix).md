# ba- ([[07_Describing Location in Asaxi]])

- - -

<span class="asaxi-script">ba-</span>

<span class="asaxi-script-alpha">ba-</span>
### Grammatical function

- **Type:** Relational Locative Prefix
- **Function:** Topological State (Lateral)
- **Meaning:** Beside, next to, alongside.

### Syntax

Attaches to the front of the noun.

- **Compound:** `ba` + `o` → **bawo** (Beside-here).

### Pronunciation

IPA: /ba/

### Example sentence

**To shěso batobo xiŕa.** _The book is beside the table._

### Derived terms

- **banů** - To be beside / To flank.
- **baŕa** - To be beside (Stative).
