# fri ([[02_Asaxi Verbs_Root (List)]])

- - -

<span class="asaxi-script">fri</span>

### Transitivity / Valency

**Transitive**
Takes an object (the entity being liberated).

### Lexical Aspect

**Achievement:** Instantaneous release.

### Grammatical Note

**[[02_Asaxi Verbs_Root (List)]]:** This belongs to the closed class of primitive verbs. It is a root verb and does not utilize the Universal Verbalizer *-ů* suffix.

### Semantic Field

[[Smntc_Field Existence]] / [[Smntc_Field Emotion]]

### Pronunciation

IPA: /fɹi/
*Phonotactic Note:* This is the permitted exception to the rule forbidding `r` followed by `i`.

### Translations

- English: to set free, to liberate, to release, to unleash
- Polish: uwolnić, wyzwolić

### Example sentence

**To wo no fri.**
_I set you free._

x

### Etymology

Borrowed from English **"Free"**.
