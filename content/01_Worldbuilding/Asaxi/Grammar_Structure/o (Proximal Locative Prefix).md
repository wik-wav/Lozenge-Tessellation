# o ([[07_Describing Location in Asaxi]])

- - -

<span class="asaxi-script">o</span>

### Grammatical function

- **Type:** Proximal Demonstrative Adverb / Prefix
- **Function:** **Immediate Deixis**
- **Meaning:** "Here", "This (place)", "Immediate vicinity".

### Usage Notes

* **As Prefix (`o-`):** Attaches to a noun to specify it is "right here" (e.g., `o-shěso` "This book here").
* **As Adverb (`o`):** Stands alone to indicate the location.
    * *Example:* **To apo o.** ("The apple is here").
* **As Tense (`o-`):** Used as a prefix for Immediate Tense (e.g., `ozè-` "Just now").

### Pronunciation

IPA: /o/

### Example sentence

**To wo o xiŕa.**
_I am here._

### Etymology

Sound symbolism for "Self/Center" (Round mouth shape, holding space).
