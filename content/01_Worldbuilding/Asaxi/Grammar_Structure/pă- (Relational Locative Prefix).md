# pă- ([[07_Describing Location in Asaxi]])

- - -

<span class="asaxi-script">pă</span>

### Grammatical function

- **Type:** Relational Locative Prefix
- **Function:** Topological State (Exteriority)
- **Meaning:** Outside, external to.

### Syntax

Attaches to the front of the noun.

- **Compound:** `pă` + `o` → **păwo** (Outside-here).

### Pronunciation

IPA: /paɪ/

### Example sentence

**To John păkamm xiŕa.** _John is outside the building._

### Derived terms

- **[[pănů (verb)|pănů]]** - To exit / To go outside.
- **păŕa** - To be outside (Stative).
