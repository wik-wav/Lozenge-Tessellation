# Proposal — 200 More Concrete Nouns (round 2)

**Mode:** reviewed. **Strategy:** gap-fill the second tier of common concrete nouns against the 667 already in the vault. **Loans:** ~16, marked **†** (naturalised Pl/Ru/Jp). **Cls** = W(arm)/C(old). Rules applied: shortness, head-final compounding, repeated-vowel→consonant-harmony, back-vowel+aa→á, loan endings (consonant→è / a→á), class by sense.

> Review tips: strike/rename freely; flag class or form changes. Examples short (SOV; location-as-verb). On approval I write full entries + Polish + back-refs as before.
