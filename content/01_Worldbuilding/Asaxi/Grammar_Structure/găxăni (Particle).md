# găxăni ([[02_Particles in Asaxi]])

- - -

<span class="asaxi-script">găxăni</span>

<span class="asaxi-script-alpha">găxăni</span>
### Grammatical function

- **Type:** Temporal Adverb / Phrase
- **Function:** **Eternal Direction**
- **Meaning:** "Forever", "For eternity", "Into infinity", "Endlessly".

### Usage Note

Distinct from **[[onå (FOREVER Aspectual Marker)|onå]]** (Always/Forever).
* **onå:** Static/Constant state. "I will always love you." (State of being).
* **găxăni:** Active trajectory. "I will run forever." (Movement into the infinite).

### Syntax

Functions as a **Floating Adverb** (Pre-Verbal) or **Sentence-Final Particle**.

### Pronunciation

IPA: /gaɪɦaɪɲi/

### Example sentence

**To wo no găxăni jåijo.**
_I want to see you for eternity._ (Lit: I want to see you into-infinity).

### Etymology

**[[găxă (noun)|găxă]]** (Infinity) + **[[ni (Relational Particle)|ni]]** (Towards/Into).
*Lit:* "Into Infinity."

### Synonyms

- **[[onå (FOREVER Aspectual Marker)|onå]]** (Always - Static).
