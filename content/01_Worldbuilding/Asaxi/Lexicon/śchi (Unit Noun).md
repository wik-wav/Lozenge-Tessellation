# śchi ([[01_Asaxi Nouns (List)]])

- - -

<span class="asaxi-script">śchi</span>

### Noun class (warm / cold)

**Cold**
- Reasoning: Abstract unit of measurement.

### Pronunciation

IPA: /ɕt͡ɕʲi/
*Phonotactics:* A dense palatal cluster. /ɕ/ (soft s) + /t͡ɕ/ (soft ch) + /i/.

### Semantic field

[[Smntc_Field Numerals]] / Weights & Measures

### Translations

- English: centimeter, cm, unit of length
- Polish: centymetr

### Example sentence

**To shěso dam sè śchi.**
_The book is 10cm (long/thick)._

### Etymology

Borrowed and shortened from Japanese **センチ** (*senchi*).
*Reduction:* `senchi` $\rightarrow$ `schi` $\rightarrow$ **śchi**.

### Derived terms

- **śchinů** (To measure X cm / To be X tall).
- **xaśchi** (Meter? / "Thousand-cm" - TBD if we use metric prefixes or new words).
