# xa- ([[39_Numerals & Mathematics]])

- - -

<span class="asaxi-script">xa-</span>

<span class="asaxi-script-alpha">xa-</span>
### Grammatical function

- **Type:** Number Prefix
- **Function:** **Thousands**
- **Logic:** Multiplies the attached digit by 1000.

### Pronunciation

IPA: /ɦa/

### Example sentence


#### Example 1

- **Asaxi:** xasă
- **English:** 1000
- **Polish:** x

#### Example 2

- **Asaxi:** xatam
- **English:** 2000
- **Polish:** x
