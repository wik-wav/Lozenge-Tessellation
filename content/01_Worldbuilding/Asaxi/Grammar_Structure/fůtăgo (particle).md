# fůtăgo ([[01_Asaxi Nouns (List)]])

- - -

<span class="asaxi-script">fůtăgo</span>

<span class="asaxi-script-alpha">fůtăgo</span>
### Noun class (warm / cold)

**Cold**
- Reasoning: Abstract quantity.

### Grammatical function

- **Type:** Number Noun (Indefinite Quantifier)
- **Meaning:** "Some", "A number of", "Several", "An unspecified amount (greater than zero)".

### Pronunciation

IPA: /fuu̯t̪aɪɡo/

### Semantic field

[[Smntc_Field Numerals]]

### Usage Note

Used when the exact count is unknown or irrelevant, but existence is confirmed.
* **Structure:** Acts as a **Floating Quantifier**.
* **Example:** `To fůtăgo sháma...` ("Some people...").

### Example sentence

**To fůtăgo shěsa tobo nanů.**
_Some books are on the table._

### Etymology

**[[fů (root word)|fů]]** (Lack/Unknown) + **[[tă (particle)|tă]]** (Plus/Positive) + **[[sigo (noun)|(si)go]]** (Number).
*Lit:* "Unknown-Positive-Number."

### Antonyms

- **[[dzeŕo (Number)|dzeŕo]]** (Zero / None).
- **[[sigo (noun)|sigo]]** (Number - specific).

### Derived terms

- **-go** quantifier family: [[dăgo (particle)|dăgo]] (many), [[hjigo (particle)|hjigo]] (few)
