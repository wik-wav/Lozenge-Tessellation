# ŋo ([[01_Asaxi Nouns (List)]])

- - -

<span class="asaxi-script">ŋo</span>

### Noun class (warm / cold)

**Cold**
- Reasoning: Abstract unit of measurement.

### Pronunciation

IPA: /ŋo/

### Semantic field

[[Smntc_Field Numerals]] / Weights & Measures

### Translations

- English: weight (general), kilogram, kilo
- Polish: waga, ciężar, kilogram

### Usage Note (Animate vs Inanimate)

* **Animate Subject:** Uses the verb **[[ŋonů (verb)|ŋonů]]** ("To weigh").
    * `To wo tamda ŋonů.` ("I weigh 200").
* **Inanimate Object:** Uses the structure `[Subject] [Number] sè ŋo xiŕa` ("Thing is X of weight").
    * **To onýj shěso tam sè ŋo xiŕa.** ("The book is 2kg").

### Etymology

Arbitrary root for heavy measurement.

### Derived terms
- **xaŋo** (A ton / Thousand kilos).
- **[[ŋonů (verb)]]** (To weigh in kilos - Intransitive).
- **[[ŋoŕů (verb)]]*** (To burden / Add weight).
