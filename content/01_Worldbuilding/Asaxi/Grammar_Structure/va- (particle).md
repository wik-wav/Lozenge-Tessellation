# va- ([[07_Describing Location in Asaxi]])

- - -

<span class="asaxi-script">va-</span>

<span class="asaxi-script-alpha">va-</span>
### Grammatical function

- **Type:** Relational Locative Prefix
- **Function:** Topological State (Interiority)
- **Meaning:** Inside, within, enclosed by.

### Syntax

Attaches to the front of the noun (or proximal prefix).

- **Compound:** `va` + `o` → **vawo** (Inside-here).

### Pronunciation

IPA: /va/

### Example sentence

**To shěso vashěsokam xiŕa.** _The book is inside the library._ (Standard Locative).

### Derived terms

- **[[vanů (verb)]]** - To enter / To inhabit.
- **vaŕa** - To be inside (Stative).
