# hùfwoŕa ([[21_Existential Logic & The Validity System|Stative Verb]])

- - -

<span class="asaxi-script">hùfwoŕa</span>

### Grammatical function

- **Type:** Stative Validity Verb
- **Function:** Epistemic Modality (Supposition)
- **Meaning:** To be uncertain, to be obscured, "It is unclear."

### Pronunciation

IPA: /hɯwfʷoɾa/

### Semantic field

Abstract / Logic

### Translations

- English: is uncertain, is possible, might be
- Polish: jest niepewne, może

### Example sentence

**Ko pashěsonů hùfwoŕa.** _It is uncertain if she will read._ / _She might read._ (Lit: She will-read is-undercloud).

### Etymology

**[[hùfwo (noun)|hùfwo]]** (Uncertainty/Undercloud) + **[[xiŕa (Particle)|-ŕa]]** (Validity Marker). _Logic:_ "It exists as an obscurity."

### Synonyms

x

### Antonyms

- **xiŕa** (It is / Fact).
- **xăxiŕa** (It is indeed / Certainty).
- **náhùfwoŕa** (Is not uncertain).
- **náxăxùfwoŕa** (Is absolutely NOT uncertain).
    - _Phonotactic Note:_ The `h` in `hù` mutates to `x` because it follows the voiced fricative context of `xă`.
