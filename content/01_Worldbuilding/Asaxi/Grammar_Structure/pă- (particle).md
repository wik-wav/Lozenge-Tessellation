# pă- ([[07_Describing Location in Asaxi]])

- - -

<span class="asaxi-script">pă</span>

<span class="asaxi-script-alpha">pă</span>
### Grammatical function

- **Type:** Relational Locative Prefix
- **Function:** Topological State (Exteriority)
- **Meaning:** Outside, external to.

### Syntax

Attaches to the front of the noun.

- **Compound:** `pă` + `o` → **păwo** (Outside-here).

### Pronunciation

IPA: /paɪ/

### Example sentence


#### Example 1

- **Asaxi:** to john păkamm xiŕa.
- **English:** John is outside the building.
- **Polish:** x

### Example Sentence 2


#### Example 1

- **Asaxi:** va aśpỏ, pă nona zèxiŕa.
- **English:** There were other things in the stocking.
- **Polish:** x

### Derived terms

- **[[pănů (verb)|pănů]]** - To exit / To go outside.
- **păŕa** - To be outside (Stative).

### Usage Note

**Sense 2 ("other").** Detached from a locative host, bare **pă** before a noun means "other / another / else" — that which stands *outside* the thing under discussion. Compare the lexicalized [[păshá (noun)|păshá]] ("another person, outsider"). Also: `pă sháma` ("everyone else"), `pă åkamm` ("the next moment"), `pă pỏpỏ` ("the other rabbit"). First attested in [[onă gaksamipỏpỏ (The Velveteen Rabbit)]].
