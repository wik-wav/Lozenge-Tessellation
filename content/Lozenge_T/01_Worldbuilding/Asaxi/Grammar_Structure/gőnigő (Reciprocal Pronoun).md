# gőnigő ([[13_Pronouns in Asaxi]])

- - -

<span class="asaxi-script">gőnigő</span>

### Grammatical function

- **Type:** Reciprocal Pronoun
- **Function:** **Mutual Action**
- **Meaning:** "Each other", "One another".

### Usage Note

Used with plural subjects to indicate that the action is shared or exchanged between them. It can occupy the Object or Oblique slot.

### Pronunciation

IPA: /ɡoɪɲiɡoɪ/

### Example sentence

**To wa gőnigő ijo.** _We see each other._

**To wa zá gőnigő aśù.** _We walk with each other._

### Etymology

**[[gő (Pronoun)|gő]]** (One/Entity) + **[[ni (Relational Particle)|ni]]** (Towards) + **gő** (One/Entity). _Lit:_ "One to one."
