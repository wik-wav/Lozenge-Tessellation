# pùxă ([[33_Desiderative Subjunctive Moods]])

- - -

<span class="asaxi-script">pùxă</span>

<span class="asaxi-script-alpha">pùxă</span>
### Grammatical function

- **Type:** Desiderative Particle (Sentence Final)
- **Function:** **Aversive Marker** (Negative Wish)
- **Meaning:** "I hope not", "God forbid", "Lest".

### Pronunciation

IPA: /pɯɦaɪ/

### Example sentence

**Topo toponů pùxă.** _I hope it doesn't rain._

### Etymology

**[[pù- (Relational Locative Prefix)|pù]]** (Below) + **[[xă (Particle)|xă]]** (Indeed/Want). _Lit:_ "Under-want" / "Base-wish."

### Synonyms

x

### Antonyms

- **dăxă** (Hopefully).
