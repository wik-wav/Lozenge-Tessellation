# fůkő ([[01_Asaxi Nouns (List)]])

- - -

<span class="asaxi-script">fůkő</span>

### Noun class (warm / cold)

**Warm**
- Reasoning: Intense emotional state (hot/destructive).

### Pronunciation

IPA: /fuu̯koɪ/

### Semantic field

[[Smntc_Field Emotion]] / Virtues & Failings
[[Smntc_Field Conflict]]

### Translations

- English: un-empathy, blind hatred, detestation, loathing, antipathy
- Polish: nienawiść, odraza, brak empatii

### Usage Note

Implies a state of complete emotional disconnection that results in hostility. Unlike **tètáko** (Conflict/Fight), which can be honorable, **fůkő** is a failure of the soul ("Un-feeling").

### Example sentence

**To wo ni xő fůkő ůchů.**
_I feel hatred towards him._

### Etymology

**[[fů (root word)|fů]]** (Lack/Un-) + **[[kő (noun)|kő]]** (Empathy/Resonance).
*Lit:* "Empathy-lessness."

### Antonyms

- **kő** (Empathy).
- **dăsùki** (Love).

### Derived terms

- **fůkőnů** (To hate / To detest).
